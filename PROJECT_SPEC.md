# Спецификация проекта: Neural Icon Forge (v0.0.5)

## Общее описание
Веб-приложение для генерации иконок на основе алгоритмических правил. Пользователь настраивает параметры (тема, стиль, сложность, асимметрия), и система генерирует уникальную иконку в реальном времени. Готово к деплою на GitHub Pages.

## Технический стек
- **Языки**: HTML5, CSS3, JavaScript (ES6+)
- **Хранилище**: LocalStorage (без бэкенда)
- **Графика**: Canvas 2D + экспорт в PNG/SVG
- **Архитектура**: Модульная (ES Modules)

## Основные функции v0.0.2
1. **Дашборд** — статистика и миниатюры последних 6 иконок.
2. **Генератор** — панель управления с 4 параметрами:
   - Тематика (abstract, nature, tech, business, art)
   - Стилистика (minimalist, vibrant, pastel, monochrome, gradient)
   - Сложность (1–10) — влияет на количество фигур
   - Асимметрия (0–100%) — смещение фигур относительно центра
3. **История** — список всех сгенерированных иконок с возможностью скачать PNG/SVG.
4. **Настройки** — имя пользователя и тема интерфейса (заготовка).

## Алгоритм генерации (Generator.js)
1. На основе темы выбирается цветовая палитра из `presets.js`.
2. Количество фигур = `3 + (complexity / 10) * 7` (от 3 до 10).
3. Для каждой фигуры случайно выбирается тип: круг, прямоугольник, треугольник, звезда, произвольная кривая.
4. Позиция фигуры зависит от асимметрии: чем выше %, тем больше разброс относительно центра.
5. Все фигуры отрисовываются на Canvas с наложением теней и смешиванием (blend modes).
6. Готовый результат сохраняется в историю (максимум 50 записей).

## API модулей
📦 Модули
1. app.js — Главный модуль
Ответственность:

>Инициализация всех модулей

>Управление состоянием приложения

>Роутинг (переключение вкладок)

>Обработка пользовательских событий

>Загрузка CSV данных

2. UIManager.js — Менеджер интерфейса
Ответственность:

>Рендеринг DOM элементов

>Обновление статистики

>Отрисовка истории

>Отрисовка последних иконок

3. Generator.js — Ядро генерации
Ответственность:

>Основная логика генерации

>Отрисовка на Canvas

>Экспорт в PNG/SVG

>Применение эффектов

4. ShapeLibrary.js — Библиотека фигур
Ответственность:

>Загрузка фигур из CSV

>Хранение библиотеки фигур

>Отрисовка фигур на Canvas

>Генерация звезд и сложных форм

5. ColorPalette.js — Цветовые палитры
Ответственность:

>Генерация цветовых схем

>Получение палитр по стилю и домену

>Конвертация цветов (HEX ↔ HSL)

>Генерация вариаций цветов

6. TextureGenerator.js — Генератор текстур
Ответственность:

>Генерация паттернов

>Создание текстур

>Наложение эффектов

7. IconComposer.js — Композитор иконок
Ответственность:

>Сборка слоев иконки

>Композиция из различных элементов

>Применение стилей

8. Storage.js — Хранилище
Ответственность:

>Абстракция над LocalStorage

>Сохранение и загрузка данных

>Очистка хранилища

9. presets.js — Библиотека пресетов
Ответственность:

>Определение доменов

>Определение стилей

>Определение категорий

>Конфигурации по умолчанию

## Деплой
Проект полностью статический. Достаточно загрузить папку на GitHub и включить GitHub Pages в настройках репозитория (ветка main, папка /).
Или скачать к себе на компьютер и запустить через cmd командой `npx serv`.

## Требования к браузеру
