# Спецификация проекта: Neural Icon Forge (v1.0)

## Общее описание
Веб-приложение для генерации иконок на основе алгоритмических правил. Пользователь настраивает параметры (тема, стиль, сложность, асимметрия), и система генерирует уникальную иконку в реальном времени. Готово к деплою на GitHub Pages.

## Технический стек
- **Языки**: HTML5, CSS3, JavaScript (ES6+)
- **Хранилище**: LocalStorage (без бэкенда)
- **Графика**: Canvas 2D + экспорт в PNG/SVG
- **Архитектура**: Модульная (ES Modules)

## Структура проекта
```
├── index.html # Основная разметка
├── style.css # Глобальные стили (CSS-переменные, адаптив)
├── app.js # Роутер, инициализация, связь модулей
├── modules/
│ ├── UIManager.js # Рендеринг, обновление DOM
│ ├── Generator.js # Ядро генерации (алгоритмы + отрисовка)
│ ├── Storage.js # Обертка над LocalStorage
│ └── presets.js # Библиотека тем и стилей (легко расширяется)
└── docs/
└── PROJECT_SPEC.md # Этот файл

```

## Основные функции
1. **Дашборд** — статистика и миниатюры последних 6 иконок.
2. **Генератор** — панель управления с 4 параметрами:
   - Тематика (abstract, nature, tech, business, art)
   - Стилистика (minimalist, vibrant, pastel, monochrome, gradient)
   - Сложность (1–10) — влияет на количество фигур
   - Асимметрия (0–100%) — смещение фигур относительно центра
3. **История** — список всех сгенерированных иконок с возможностью скачать PNG/SVG.
4. **Настройки** — имя пользователя и тема интерфейса (заготовка).

## Алгоритм генерации (Generator.js)
1. На основе темы выбирается цветовая палитра из `presets.js`.
2. Количество фигур = `3 + (complexity / 10) * 7` (от 3 до 10).
3. Для каждой фигуры случайно выбирается тип: круг, прямоугольник, треугольник, звезда, произвольная кривая.
4. Позиция фигуры зависит от асимметрии: чем выше %, тем больше разброс относительно центра.
5. Все фигуры отрисовываются на Canvas с наложением теней и смешиванием (blend modes).
6. Готовый результат сохраняется в историю (максимум 50 записей).

## API модулей
### `UIManager`
- `updateStats(stats)` — обновляет цифры на дашборде
- `renderHistory(history)` — рендерит список иконок в истории
- `renderRecent(items)` — рендерит миниатюры на дашборде

### `Generator`
- `generate(params)` → `{ shapes, background, theme, style }`
- `drawIcon(ctx, width, height, data)` — отрисовывает данные на canvas
- `download(format, encodedData)` — скачивает PNG/SVG

### `Storage`
- `save(key, data)` — сохраняет в localStorage
- `load(key, default)` — загружает
- `clear()` — очищает все данные приложения

## Расширение (для будущих версий)
- **Новые типы фигур** — добавить в `createShape()`.
- **Дополнительные параметры** — цветовая схема, количество цветов, текстуры.
- **Пресеты пользователя** — сохранять настройки как шаблоны.
- **Нейросетевая логика** — заменить `createShape()` на вызов API модели (например, TensorFlow.js или внешний эндпоинт).

## Деплой
Проект полностью статический. Достаточно загрузить папку на GitHub и включить GitHub Pages в настройках репозитория (ветка main, папка /).
